Xymon APT packages

Packages of Xymon for Debian and Ubuntu: an unofficial rebuild of Debian's own xymon package for releases that do not carry that version. Packaging lives in xymon-apt.

⚠️ Highly experimental. This packaging is new and has seen no production use; versioning, suites and repository structure may still change without notice. Do not point production machines at it yet.

Install

curl -fsSLo /etc/apt/sources.list.d/xymon.sources \
  https://xymon-monitoring.github.io/xymon-apt/$(. /etc/os-release; echo $VERSION_CODENAME)/xymon.sources
apt update
apt install xymon          # server (pulls in xymon-client)
apt install xymon-client   # client only

The file names the repository and carries the signing key, which then vouches for this repository alone.

Suites

bookwormxymon.sourcespackages
noblexymon.sourcespackages
trixiexymon.sourcespackages

One suite per release, component main. Every published version stays available; apt list -a xymon shows them.

Channels

Each release also has three pre-release suites, named as xymon-rpm names its channels. They are not enabled by xymon.sources, which says how to add one.

<release>-snapshot builds of upstream main, nightly: pre-releases of the next version, with no release testing
<release>-preview previews of each unreleased milestone, from xymon-experimental: the 2 newest of every milestone
<release>-preview-next the previews of the next release alone — the usual choice for testing a preview

Add one of them, and not a snapshot together with a preview: they are different lines of code. For testing, not production.
